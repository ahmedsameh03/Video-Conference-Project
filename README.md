# Video-Conference-Project

Graduation Project
Smart-Secure Video Conference Web Application (SEEN), Grade (A+)
Developed a secure, scalable video conferencing web application using WebRTC, Node.js, MongoDB, and WebSockets,
incorporating robust authentication and real-time encrypted communication. Implemented email-based OTP verification, bcrypt
password hashing, and encrypted user credentials in MongoDB.
Integrated end-to-end encryption (E2EE) for media streams using AES-GCM-SIV to ensure privacy and data integrity during peer-to-peer
calls.
